# Learn Dvorak

A typing tutor that teaches the Dvorak keyboard layout by having the learner type generated text and showing them where they're slow or inaccurate.

## Language

**Test**:
One pass through a freshly generated passage, ending in a WPM result.
_Avoid_: Game, round, attempt (for the live run)

**Attempt**:
A completed Test as recorded in the learner's history.
_Avoid_: Score, run

**WPM**:
Words per minute, where a word is any five correctly typed characters (spaces included).
_Avoid_: Speed, score

**Missed Key**:
The key the learner should have pressed when they made a typing error, counted per Test.
_Avoid_: Bad key, wrong key
